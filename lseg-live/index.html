02 / REPRODUCE

Query → save → publish.

1. Query real data

Python lseg-data uses an explicit Platform session. Workspace is not required. Credentials come from repository Secrets on GitHub or hidden prompts locally, never from this page.

2. Save a Plotly chart

Validate dates and prices, then generate both pages, CSV and JSON from one response. No synthetic fallback, interpolation or forward filling.

3. Change the stock

Edit RIC in lseg_chart/update.py and push to main. Actions queries the new stock and publishes its plot. You can also choose Run workflow → main without a code change.

Source code, freshness and failure behavior

Changes to query/render code or workflow settings trigger an update; generated data does not trigger another query. Opening this page does not query LSEG. Labels always describe the last successful response, not a pending code change. If authentication, validation or publishing fails, Actions reports the failure and the previous successful result retains its original instrument and timestamp. There is no scheduled query or forced session takeover.
