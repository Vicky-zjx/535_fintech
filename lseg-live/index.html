02 / REPRODUCE

Query → save → publish.

1. Query real data

Python lseg-data uses an explicit Platform session on a GitHub runner. Workspace is not required. Credentials come from repository Secrets, never from this page.

2. Save a Plotly chart

Validate dates and prices, then save the chart, CSV and JSON together. No synthetic fallback, interpolation or forward filling.

3. Update this page

Open the workflow above and choose Run workflow → main. A successful run commits only these three generated files and requests a Pages build. Refresh this page after the build finishes.

Source code, freshness and failure behavior

Updates are manual; opening this page does not query LSEG. The timestamp is the last successful data query, not a guarantee that every exchange session is covered. If authentication, validation or publishing fails, Actions reports the failure and the previous successful result stays available. Do not interpret an old result as a new query.
