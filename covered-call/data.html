OBSERVED UNIVERSE

Actual strikes. No invented grid.

Rule: choose the smallest actually observed same-Friday AAPL call strike ≥ 1.05 × Monday spot. Membership requires a real historical LSEG BID, ASK, or TRDPRC_1 observation available by Monday’s order time. An all-missing row or a constructible RIC does not establish a listed contract. Later observations cannot establish earlier eligibility.

REPRODUCE

One configuration. One book.

From the repository root, use the existing Python environment. The engine tests use small, explicitly synthetic fixtures only for accounting tests; the build requires an explicitly real LSEG cache.

.venv/bin/python -m unittest covered_call.test_engine -v .venv/bin/python -m covered_call.build

Strategy settings live in covered_call/config.py, including ENTRY_TIME and INITIAL_CASH. Initial cash remains $30,000; negative cash is a margin debit allowed only when the entry passes the Reg T checks. Rebuilding uses cached data and writes only this assignment’s book.js and bundled chart library.

A separate, local real-data pull

Log in to LSEG Workspace, then choose a new output filename and an explicit real observed-universe cache. The utility requests only exact RICs evidenced in that cache. It does not create strikes, fill gaps, or claim to expand historical chain coverage. A broader run requires a broader verified historical contract source. Existing real caches are preserved; raw responses and request errors are retained.

.venv/bin/python -m covered_call.fetch_lseg --universe-cache covered_call/data/aapl_hourly_verified.json --output covered_call/data/aapl_hourly_new.json .venv/bin/python -m covered_call.build --cache covered_call/data/aapl_hourly_new.json

The pull uses 60-minute stock and option bars. The source labels the start of each hour; timestamps are advanced exactly one hour to represent bar availability, then converted to New York time. Only regular-session bars are used.

IDENTIFIERS

A tested RIC convention.

The default RIC constructor reproduces the assignment’s unpadded-day examples. Actual AAPL requests returned data for padded single-digit days and failed for their unpadded equivalents. The ingestion adapter explicitly enables this tested provider format. The actual returned RIC is recorded in the blotter.

Assignment example: AAPLH72620500.U^H26 Verified provider form: AAPLH072632500.U^H26 September provider form: AAPLI042633500.U^I26

The 5-digit strike is in cents; for calls, both the month code and expired suffix use A–L. The previous assignment’s confirmed put-suffix correction remains intact.
